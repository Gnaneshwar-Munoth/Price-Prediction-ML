# Price Prediction using Machine Learning

## Overview
Developed a machine learning model to predict prices using historical data.

## Objective
To build an accurate prediction system using machine learning algorithms.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- XGBoost

## Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Engineering
5. Model Training
6. Model Evaluation

## Results
- Achieved 97% prediction accuracy
- Improved model score from 0.88 to 0.97

## Skills Demonstrated
- Machine Learning
- Data Analysis
- Feature Engineering
- Model Optimization
